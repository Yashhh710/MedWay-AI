## 🚀 Razorpay AI Buildathon 2026

**MedWay AI** is a healthcare-assistance prototype built for the **Razorpay AI Buildathon 2026**.

The idea is simple:

> **Healthcare should not become difficult just because you're in an unfamiliar city or country.**

When travelers get sick or need medical assistance, they often face problems such as finding a trusted doctor, locating a nearby pharmacy, understanding prescriptions, communicating with healthcare professionals, or getting emergency help.

MedWay AI brings these experiences together in **one simple platform**.

# 💡 The Problem

Traveling in an unfamiliar place can make even a simple healthcare problem stressful.

A traveler may not know:

* 🏥 Which hospital to visit
* 👨‍⚕️ Which doctor to contact
* 💊 Where to find a medicine
* 📋 What a handwritten prescription says
* 🌐 How to communicate with a doctor
* 🚨 Where the nearest emergency facility is
* 📅 How to book a consultation
* 💰 How much a medicine or consultation may cost

Existing healthcare services are often scattered across multiple applications.

### The idea behind MedWay AI

**One platform → Multiple healthcare needs.**

```text
                    MEDWAY AI
                        │
       ┌────────────────┼────────────────┐
       │                │                │
```

# 📋 6. AI Prescription Reader

One of the key AI features of MedWay AI.

Users can upload a prescription image and extract useful information.

### AI can attempt to identify

```text
Patient Name
      ↓
Doctor Name
      ↓
Hospital / Clinic
      ↓
Prescription Date
      ↓
Medicine Names
      ↓
Dosage
      ↓
Frequency
      ↓
Duration
      ↓
Instructions
```

### Example

Instead of trying to understand:

> handwritten prescription

the user can receive structured information such as:

```text
Medicine: Paracetamol
Dosage: 500 mg
Frequency: 2 times/day
Duration: 3 days
Instruction: After food
```

### ⚠️ Important

Prescription extraction is an **AI-assisted interpretation**, not a medical diagnosis.

Users should always verify extracted information with a qualified doctor or pharmacist before taking medication.

# 🤖 7. AI Healthcare Assistant

MedWay AI includes a conversational healthcare assistant designed to provide simple informational guidance.

### Example questions

```text

🏥 Find a nearby hospital

```

### Example workflow

```text

  ↓
Healthcare Question
  ↓
AI Assistant
  ↓
Understand Intent
  ↓
Generate Informational Response
  ↓
Suggest Next Action
```

The assistant is designed to **assist**, not replace qualified medical professionals.

# 🔐 Privacy & Safety

MedWay AI is currently a **hackathon prototype**.

The application should **not be considered a replacement for professional medical advice**.

### Users should always

* ✅ Verify prescription information
* ✅ Confirm medicine dosage
* ✅ Consult qualified healthcare professionals
* ✅ Verify healthcare provider information
* ✅ Use official emergency services during real emergencies

### Do not use MedWay AI alone for

* ❌ Emergency medical decisions
* ❌ Diagnosing serious medical conditions
* ❌ Changing prescribed medication
* ❌ Determining critical medication dosage

# ⚙️ Getting Started

## 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

## 2. Open the project

```bash
cd MedWay-AI
```

```text
Open the project

      ↓
Right click index.html
      ↓
```

---

# 🔑 Environment Variables

If external APIs are connected, keep API credentials outside your frontend source code.

Example:

```env
AI_API_KEY=your_api_key
MAP_API_KEY=your_api_key
TRANSLATION_API_KEY=your_api_key
```

### ⚠️ Never commit secret API keys

Do **not** put private API keys directly inside:

```text
index.html
assistant.js
prescription.js
map.js
```

For production, sensitive API calls should be handled through a secure backend/serverless function.
